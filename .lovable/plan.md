

# Обновление цветов и шрифта по макету

## Что меняем

Пользователь указал точные значения цветов и шрифт:
- Кнопки: `#ffde59` (желтый)
- Желтый бэкграунд: `#898888` (серый фон)
- Шрифт: Poppins (для всего текста, не только заголовков)

## Технические изменения

### 1. `src/index.css` -- обновить CSS-переменные
- Заменить `--primary` на HSL-эквивалент `#ffde59` (примерно `48 100% 67%` -- уже близко, уточним)
- Обновить `--lemon-300`, `--lemon-400` под точный `#ffde59` (HSL: `48 99% 67%`)
- Обновить фоновые переменные: `--muted` и другие "желтые фоны" на HSL-эквивалент `#898888` (HSL: `0 0% 53%`) -- это серый цвет для фоновых секций

### 2. `tailwind.config.ts` -- шрифт Poppins как основной
- Заменить `fontFamily.sans` с `Inter` на `Poppins` чтобы весь текст был Poppins
- Оставить `fontFamily.heading` тоже Poppins

### 3. `index.html` -- упростить подключение шрифтов
- Можно убрать Inter из Google Fonts и оставить только Poppins (с нужными весами)

### 4. Компоненты -- обновить inline-цвета кнопок
Во всех компонентах где кнопки используют `bg-lemon-300`, `bg-lemon-400` -- заменить на inline style `backgroundColor: '#ffde59'` или обновить CSS-переменную `--lemon-400` на точный `#ffde59`, чтобы `bg-lemon-400` давал нужный цвет.

**Затронутые файлы:**
- `src/pages/Home.tsx` -- Hero кнопки
- `src/components/Header.tsx` -- CTA кнопка
- `src/components/CleaningPricing.tsx` -- кнопки "Zamow sprzatanie"
- `src/components/TrustIndicators.tsx` -- иконки (lemon-100, lemon-600)

### 5. Подход к цветам

Вместо замены во всех компонентах по отдельности, обновим CSS-переменные в `src/index.css`:
- `--lemon-400: 48 99% 67%` (точный #ffde59)
- Серый фон секций: добавим утилити-класс или обновим нужную переменную

Это позволит всем компонентам, использующим `bg-lemon-400`, автоматически получить правильный цвет.
