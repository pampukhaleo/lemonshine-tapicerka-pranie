## Уточнение hero-паттерна

Сейчас фото растянуто на всю ширину секции, а градиент лежит поверх во всю ширину. На скрине картинка занимает только правую часть (~40% ширины), а левые ~60% — это плотный градиент lemon→mint без фото под ним.

## Что меняем

В трёх файлах (`src/pages/Home.tsx`, `src/components/Hero.tsx`, `src/components/window/WindowHero.tsx`):

1. Базовый слой секции — сплошной градиент `bg-gradient-to-r from-lemon-200 via-mint-200 to-mint-100` (без фото).
2. Фото добавляем отдельным абсолютным блоком, прижатым к правому краю:
   - desktop: `right-0 top-0 h-full w-[55%]`, `bg-cover bg-center`
   - слева на фото — мягкий переход к градиенту через дополнительный слой `bg-gradient-to-r from-lemon-200 via-lemon-200/80 to-transparent w-[40%]`, чтобы стык картинки и градиента был плавный, как на скрине.
3. Mobile (`< md`): фото скрываем (`hidden md:block`), фон остаётся чистым градиентом — текст читается без перекрытия. Это соответствует прошлой договорённости про мобильную версию.
4. Контент (h1, p, кнопки) остаётся в `container`, ограничен по ширине `max-w-xl`, прижат влево (`text-left`, без `mx-auto` на Home).

## Схема

```text
desktop (md+):
+------------------------------------------------------+
|  gradient lemon→mint (≈60%)         [   ФОТО (≈40%) ]|
|  H1                                  плавный стык    |
|  подзаголовок                        через доп.      |
|  [CTA1] [CTA2]                       градиент слева  |
+------------------------------------------------------+

mobile:
+---------------------------+
|  gradient lemon→mint      |
|  H1                       |
|  подзаголовок             |
|  [CTA1]                   |
|  [CTA2]                   |
+---------------------------+
```

## Ограничения

- Тексты, кнопки, ссылки, номера телефонов, обработчики — не трогаем.
- Никаких изменений в других секциях страниц и в бизнес-логике.
- Фото для каждой страницы остаётся своё (`sprzatanie-hero.jpg`, `pranie-tapicerki-hero.jpg`, `mycie-okien-hero.jpg`).
